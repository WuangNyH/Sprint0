### 3.1 🔘 Button — `CButton.vue`

**Variants:** primary, secondary, outline, text, danger, ghost, icon
**Sizes:** sm, md, lg (md = cao 40px mặc định)

**HTML mẫu**

```html
<button class="c-btn c-btn--primary c-btn--md" aria-label="Lưu">
  <span class="c-btn__icon" aria-hidden="true"><svg/></span>
  <span class="c-btn__text">Lưu</span>
</button>
```

**SCSS (snippet)**

```scss
.c-btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: 8px;
  border-radius: $radius-md;
  border: 1px solid transparent;
  cursor: pointer;
  transition: background .12s, transform .06s;

  &--md { height: 40px; padding: 0 $space-md; font-size: $fs-base; }
  &__icon { display:inline-flex; }

  &--primary {
    background: var(--color-primary);
    color: #fff;
    &:hover { background: var(--color-primary-dark); }
    &:disabled { opacity: .6; pointer-events: none; }
  }
  &--outline {
    background: transparent;
    border: 1px solid var(--color-border);
    color: var(--color-text);
  }
}
```

**Vue props/events (gợi ý)**

```js
props: {
  variant: { type: String, default: 'primary' },
  size: { type: String, default: 'md' },
  disabled: Boolean,
  loading: Boolean,
  icon: [String, Object],
  type: { type: String, default: 'button' }
},
emits: ['click']
```

**Accessibility**

* Icon-only: bắt buộc `aria-label`.
* Toggle button: dùng `aria-pressed`.
* Khi disabled: không nên giữ focus (tabindex=-1).

### 3.2 ✍️ Input / TextField — `CInput.vue`

**Types:** text, email, password, number, search
**States:** default / focus / error / disabled / readonly

**HTML**

```html
<label class="c-form__label" for="email">Email</label>
<div class="c-input">
  <input id="email" class="c-input__control" type="email" placeholder="you@mail.com"/>
  <button class="c-input__clear" aria-hidden="true">×</button>
</div>
<div class="c-form__error" id="email-error">Email không hợp lệ</div>
```

**SCSS**

```scss
.c-input {
  display:flex; align-items:center;
  border:1px solid var(--color-border);
  border-radius:$radius-sm;
  height:40px; padding:0 $space-sm;

  &__control { flex:1; border:none; background:transparent; outline:none; }
  &--error { border-color: var(--color-error); }
  &--disabled { background: var(--color-surface); color: var(--color-text-muted); pointer-events:none; }
}
```

**Vue props**

```js
props:{
  modelValue: [String, Number],
  type: {type:String, default:'text'},
  placeholder: String,
  disabled: Boolean,
  error: String,
  name: String,
  id: String
},
emits:['update:modelValue','blur','focus','enter']
```

**Accessibility**

* Khi lỗi: `aria-invalid="true"` và `aria-describedby` trỏ tới message.

### 3.3 🔽 Select / Dropdown — `CSelect.vue`

**Tính năng:** searchable (tùy chọn), keyboard accessible, virtualize cho list dài.

**HTML cấu trúc**

```html
<div class="c-select">
  <button class="c-select__control" aria-haspopup="listbox" aria-expanded="false">
    <span class="c-select__value">Chọn</span>
    <span class="c-select__arrow">▾</span>
  </button>
  <ul class="c-select__menu" role="listbox">
    <li role="option">Option A</li>
  </ul>
</div>
```

**Vue API**

```js
props: { options: Array, modelValue: [String, Number], searchable: Boolean },
emits: ['update:modelValue','open','close']
```

**Accessibility**

* Dùng `role="listbox"`/`role="option"`, quản lý `aria-selected`.
* Keyboard: Arrow Up/Down, Enter chọn, Esc đóng.

## 4. 🎛 Quy tắc tương tác & animation

* Kích thước target (tap target) tối thiểu: 40×40px cho mobile.
* Hover chỉ thay đổi visual, không thay đổi nội dung.
* Focus: hiển thị rõ ring (ví dụ box-shadow: 0 0 0 3px rgba(59,130,246,0.12)).
* Animation ngắn: 100–180ms, chỉ dùng `transform` & `opacity` ưu tiên.
* Disabled: giảm opacity, `pointer-events: none`.
* Error: hiển thị inline error + `aria-invalid` và role alert cho thông tin quan trọng.
