## 2. 🎨 Design tokens (cơ bản)

Sử dụng biến CSS / SCSS làm nguồn duy nhất.

**SCSS variables (ví dụ):**

```scss
// Typography
$font-family: 'Inter', system-ui, -apple-system, 'Segoe UI', Roboto, Arial;
$fs-xs: 12px; $fs-sm: 14px; $fs-base: 16px; $fs-lg: 18px;

// Spacing
$space-xxs: 4px; $space-xs: 8px; $space-sm: 12px; $space-md: 16px; $space-lg: 24px;

// Radius & shadow
$radius-sm: 6px; $radius-md: 8px; $radius-lg: 12px;
$shadow-sm: 0 1px 2px rgba(16,24,40,0.04);
$shadow-md: 0 6px 18px rgba(17,24,39,0.08);
```

**Gợi ý:** lưu tất cả token vào `_variables.scss` và expose song song bằng CSS custom properties `:root` để runtime dễ override (theme/dark mode).

## 4. 🧭 Quy ước đặt tên & cấu trúc thư mục

* **Class prefix:** `c-` (component), `l-` (layout), `u-` (utility), `p-` (page).
* **BEM:** `c-card`, `c-card__header`, `c-btn--primary`.
* **SCSS structure:**

```
/src/assets/scss/
  _variables.scss
  _mixins.scss
  components/
    _buttons.scss
    _inputs.scss
    _cards.scss
  main.scss
```

* **Component structure (Vue):**

```
/src/components/ui/
  CButton.vue
  CInput.vue
  CSelect.vue
  CCard.vue
  CModal.vue
  CTable.vue
  CToast.vue
  ...
```

## 5. 🧩 Quy chuẩn component (tóm tắt)

**Danh sách component tối thiểu cần có bản mẫu:**

* `CButton` — variants: primary / secondary / outline / danger / text; sizes: sm/md/lg; states: hover/focus/active/disabled/loading.
* `CInput` — types: text/email/password/number; states: focus/error/disabled.
* `CSelect` — searchable, keyboard accessible.
* `CCheckbox` / `CRadio` — native input + visually-hidden.
* `CSwitch` — role="switch".
* `CCard` — header/body/footer.
* `CModal` — trap focus, `aria-modal`.
* `CTable` / `ItemList` — search / sort / paging / filters / selection / actions.
* `CToast` — `aria-live="polite"`, auto-dismiss.
* Plus: Avatar, Badge, Tooltip, Loader/Skeleton, File Upload, Datepicker.

## 6. 📝 Chi tiết spec cho các component chính

### 6.1 🔘 CButton (tóm tắt)

* **Props:** `variant`, `size`, `disabled`, `loading`, `icon`.
* **HTML mẫu:**

```html
<button class="c-btn c-btn--primary c-btn--md" aria-label="Lưu">
  <span class="c-btn__icon" aria-hidden="true"><svg/></span>
  <span class="c-btn__text">Lưu</span>
</button>
```

* **Accessibility:** `aria-label` cho icon-only; `aria-pressed` cho toggle.
* **Style:** background `var(--color-primary)`, hover → `--color-primary-dark`, disabled → opacity 0.6.

---

### 6.2 ✍️ CInput

* **Props:** `modelValue`, `type`, `placeholder`, `disabled`, `error`.
* **States:** focus (ring), error (border `--color-error`), disabled (bg `--color-surface`).
* **Accessibility:** `aria-describedby` → lỗi; `aria-invalid` khi error.

---

### 6.3 🔽 CSelect

* **Tính năng:** searchable, keyboard navigation, support virtualization for long lists.
* **ARIA:** `role="listbox"` / `role="option"`; manage `aria-selected`.

---

### 6.4 🃏 CCard

* **Style:** background `--color-surface`, padding `$space-md`, radius `$radius-md`, `box-shadow: $shadow-sm`.

---

### 6.5 🪟 CModal

* **Behavior:** trap focus, close on ESC/backdrop (tùy), `role="dialog"`, `aria-modal="true"`, return focus to trigger.

---

### 6.6 📋 CTable / ItemList (tóm lược)

* **Phải hỗ trợ:** search (debounce 300ms), sort (server-side), paging (page,size), filters, column show/hide, row selection, batch actions, per-row actions, export.
* **API mẫu:** `GET /api/resource?page=1&size=20&q=...&sort=field:dir&filters=...`
* **ARIA:** `aria-sort` trên header, `aria-current` cho page.

---

### 6.7 🔔 CToast

* `role="status"`, `aria-live="polite"`, auto-dismiss default 3s, pause on hover.

---

## 7. 📋 Item List — chức năng bắt buộc (tóm tắt)

**Bắt buộc có:**

* 🔎 **Search** (quick + advanced) — debounce 300ms, minChars configurable.
* ↕️ **Sort** (ít nhất single-column) — indicator, server-side.
* 📄 **Paging** — page & size, total meta, page-size options.
* 🔍 **Filters** — chips, multi-filter.
* 🧾 **Column config** — show/hide (persist optional).
* ✅ **Row selection & Batch actions** — select-all (page) + select-all-results optional.
* ⚙️ **Per-row actions** — view/edit/delete (confirm destructive).
* 📤 **Export / Import** — export filtered; import with validation.
* ♻️ **Loading / Empty / Error states** — UX rõ ràng.
* ♿ **Accessibility** — keyboard + screen reader support.

(Chi tiết đã có trong ItemList-Spec — đây là tóm tắt chốt.)

---

## 8. ♿ Accessibility (A11y) checklist

* ✅ Tất cả interactive elements keyboard navigable.
* ✅ Dùng semantic roles & ARIA khi cần (dialog, listbox, switch, tablist, etc.).
* ✅ Focus management (modal trap & return).
* ✅ Contrast >= WCAG AA (4.5:1 với text).
* ✅ `aria-live` cho nội dung động (toasts, batch result).

## 9. ✅ QA checklist & Acceptance criteria

**Component-level checks (bắt buộc trước release):**

* [ ] Visual states: default / hover / focus / active / disabled / error.
* [ ] Props/events behavior (unit test).
* [ ] Storybook story cho mỗi state.
* [ ] Basic accessibility check (axe).

**ItemList acceptance (must pass):**

* [ ] Search (partial/exact) hoạt động.
* [ ] Sort asc/desc cho các cột định trước.
* [ ] Paging hiển thị chính xác range & tổng.
* [ ] Filters kết hợp đúng.
* [ ] Row selection + batch actions đúng & có confirm.
* [ ] Per-row actions có quyền kiểm tra.
* [ ] Export trả dữ liệu đúng filters.
* [ ] Loading/Empty/Error UI ok.
* [ ] Keyboard navigation & responsive check.

## 10. 🔗 API contract mẫu cho list / batch / export

**GET list**

```
GET /api/{resource}?page=1&size=20&q=nguyen&sort=lastName:asc&filters=status:active
```

**Response**

```json
{
  "data": [ { "id":"...", "name":"...", ... }, ... ],
  "meta": { "page":1, "size":20, "total":254, "pages":13 },
  "links": { "self":"...", "next":"...", "prev":"..." }
}
```

**POST batch**

```
POST /api/{resource}/batch
Body: { action: "delete", ids: ["id1","id2"] }
Response: { success: ["id1"], failed: [{id:"id2", error:"..."}] }
```

**POST export (async)**

* `POST /api/{resource}/export` -> 202 + jobId -> `GET /api/jobs/{jobId}` để lấy file.
