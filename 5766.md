# Java – Formatting Rules (chuẩn Google/Oracle)

- **Indent**: 4 spaces (không dùng tab).
- **Braces**: mở cùng dòng, đóng xuống dòng (K&R):

  ```java
  if (ok) {
      run();
  } else {
      rollback();
  }
  ```

- **Khoảng trắng**:

  - Sau dấu `,` và quanh toán tử: `a + b`, `map.put(k, v);`
  - Không có khoảng trắng trước `;` hay trước dấu `)`; có **1 space** trước `{`.
  - Không space giữa tên method và `(`: `doWork(arg)` (❌ `doWork (arg)`).

- **Dòng trống**:

  - 1 dòng giữa các **field group**, **constructor**, **method**.
  - 1 dòng sau block import.

- **Imports**:

  - Không dùng `*`.
  - Nhóm: **non-static** rồi đến **static**, mỗi nhóm sắp xếp theo ABC, cách nhau 1 dòng trống.

- **Chaining / Wrapping**:

  - Khi xuống dòng, **ngắt trước dấu chấm**:

    ```java
    var x = builder
        .setName(name)
        .setAge(age)
        .build();
    ```

  - Continuation indent +4.

- **Annotation**: ngắn gọn giữ cùng dòng; dài đặt trên dòng riêng:

  ```java
  @Override public String toString() { ... }
  @RequestMapping(
      method = GET,
      value = "/employees"
  )
  ```

- **Lambda**: có khoảng trắng quanh `->`, block nhiều dòng phải có `{}`:

  ```java
  list.stream().map(x -> x * 2).forEach(System.out::println);
  ```

- **Ternary**: canh thẳng hàng, dễ đọc khi dài:

  ```java
  var label = cond
      ? optionA
      : optionB;
  ```

### Cấu hình đề xuất (chọn 1 trong 2)

**Gradle + Spotless + google-java-format**

```gradle
plugins {
  id 'com.diffplug.spotless' version '6.25.0'
}
spotless {
  java {
    googleJavaFormat('1.22.0').reflowLongStrings()
    target 'src/**/*.java'
    removeUnusedImports()
    trimTrailingWhitespace()
    endWithNewline()
  }
}
```

**Maven + Spotless**

```xml
<plugin>
  <groupId>com.diffplug.spotless</groupId>
  <artifactId>spotless-maven-plugin</artifactId>
  <version>2.43.0</version>
  <configuration>
    <java>
      <googleJavaFormat version="1.22.0">
        <reflowLongStrings/>
      </googleJavaFormat>
      <removeUnusedImports/>
      <trimTrailingWhitespace/>
      <endWithNewline/>
    </java>
  </configuration>
  <executions>
    <execution>
      <goals><goal>apply</goal></goals>
    </execution>
  </executions>
</plugin>
```

# Vue.js – Formatting Rules (Vue 3 + Prettier + ESLint)

- **Indent**: 2 spaces.
- **Line length**: 100–120 ký tự.
- **Self-closing**: thẻ không nội dung tự đóng: `<img />`, `<MyButton />`.
- **Thuộc tính/Directive trong template**:

  - **Thứ tự** gợi ý (rất hữu ích cho review):

    1. Definition (`is`)
    2. List rendering (`v-for`)
    3. Conditionals (`v-if`, `v-else-if`, `v-else`, `v-show`)
    4. Render modifiers (`v-once`, `v-pre`)
    5. Global (`id`)
    6. Unique (`ref`, `key`)
    7. Two-way binding (`v-model`)
    8. Other bindings (`:prop`, `v-bind`)
    9. Other attrs
    10. Events (`@click`)
    11. Content (`v-text`, `v-html`)

- **SFC block order**: `<template>` → `<script setup>`/`<script>` → `<style>` (ưu tiên `<script setup>`).
- **Script order (Options API)**: `name, components, directives, extends, mixins, props, emits, setup, data, computed, watch, lifecycle hooks, methods`.
- **Props**: khai báo `type`, `required`, `default`.
- **One-attribute-per-line** khi nhiều attribute (đọc dễ + diff sạch).

### ESLint + Vue + Prettier

**.eslintrc.cjs**

```js
module.exports = {
  root: true,
  env: { browser: true, es2022: true, node: true },
  extends: [
    "eslint:recommended",
    "plugin:vue/vue3-recommended",
    "plugin:@typescript-eslint/recommended", // bỏ nếu không dùng TS
    "plugin:prettier/recommended",
  ],
  parser: "vue-eslint-parser",
  parserOptions: {
    ecmaVersion: "latest",
    sourceType: "module",
    parser: "@typescript-eslint/parser", // hoặc '@babel/eslint-parser' cho JS
  },
  rules: {
    // Vue template formatting
    "vue/html-self-closing": [
      "error",
      {
        html: { void: "always", normal: "never", component: "always" },
        svg: "always",
        math: "always",
      },
    ],
    "vue/max-attributes-per-line": ["error", { singleline: 3, multiline: 1 }],
    "vue/attributes-order": "error",
    "vue/order-in-components": "error",
    "vue/no-mutating-props": "error",
    "vue/no-unused-properties": [
      "warn",
      { groups: ["props", "data", "computed", "methods"] },
    ],

    // JS/TS general
    "no-var": "error",
    "prefer-const": "error",
    "no-unused-vars": "warn",
  },
};
```

## Tips đồng bộ giữa Java & Vue trong cùng repo

- **Commit hook** (Husky + lint-staged) chạy `spotlessApply` cho Java và `prettier/eslint --fix` cho Vue trước khi commit.
- **CI**: chạy `spotlessCheck` + `eslint` để fail sớm nếu lệch convention.
- **EditorConfig** để đồng bộ khoảng trắng/EOF:

  **.editorconfig**

  ```
  root = true

  [*]
  charset = utf-8
  end_of_line = lf
  insert_final_newline = true
  trim_trailing_whitespace = true

  [*.java]
  indent_style = space
  indent_size = 4
  max_line_length = 100

  [*.{js,ts,vue,json,css,scss,md}]
  indent_style = space
  indent_size = 2
  ```
