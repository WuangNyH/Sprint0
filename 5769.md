## 📦 Liệt kê và thống nhất các item common: Button, Table, Error, Popup, Dialog, Paging,...

### 1. Button

| Tên                | Mô tả                                 | Props / Thuộc tính            | Trạng thái / biến thể                    | Ghi chú                                                     |
| ------------------ | ------------------------------------- | ----------------------------- | ---------------------------------------- | ----------------------------------------------------------- |
| `Button.Primary`   | Nút chính, dùng cho hành động nổi bật | `onClick`, `disabled`, `type` | `default`, `hover`, `active`, `disabled` | Kiểu màu sắc nên thống nhất (ví dụ: `primary`, `secondary`) |
| `Button.Secondary` | Nút phụ, dùng cho hành động phụ       | tương tự                      | tương tự                                 | thường ít nổi bật hơn Primary                               |
| `Button.Icon`      | Nút chỉ chứa icon hoặc icon + text    | `icon`, `iconPosition`        | tương tự                                 | nếu dùng icon nên tuân kích thước icon chuẩn                |
| `Button.Link`      | Nút giống link (text)                 | `href`, `target`              | `default`, `hover`, `active`             | dùng để điều hướng, không dùng sự kiện onClick nặng         |

#### Quy ước chung cho Button

* Màu sắc: primary, secondary, danger, success, warning
* Kích thước: small, medium, large
* Padding / margin nội tại: nên có quy chuẩn
* Icon spacing: nếu có icon + text, khoảng cách (ví dụ: 8px)
* Accessibility: `aria-label`, keyboard focus style

### 2. Table

| Tên            | Mô tả              | Props / Thuộc tính                | Tính năng                                         | Ghi chú                                                    |
| -------------- | ------------------ | --------------------------------- | ------------------------------------------------- | ---------------------------------------------------------- |
| `Table`        | Bảng dữ liệu chuẩn | `columns`, `dataSource`, `rowKey` | sắp xếp (sort), lọc (filter), phân trang (paging) | columns định nghĩa `title`, `dataIndex`, `render`, `width` |
| `Table.Header` | Header của bảng    | —                                 | cố định, sticky                                   | nếu scroll dọc thì header vẫn hiển thị                     |
| `Table.Body`   | Thân bảng          | —                                 | dòng highlight on hover, chọn dòng                | có thể chọn nhiều dòng (multi-select)                      |
| `Table.Footer` | Footer của bảng    | —                                 | tổng hợp, hiển thị tổng, paging                   | nếu có tính tổng                                           |

#### Quy ước chung cho Table

* Bảng phải responsive: với màn hình nhỏ, cho cuộn ngang hoặc ẩn cột phụ
* Cell padding: khoảng cách nội tại (ví dụ: 12px × 16px)
* Dòng zebra (alternating row color) nếu cần
* Kiểm soát chiều rộng cột: `minWidth`, `maxWidth`
* Xử lý dữ liệu null / undefined hiển thị như “—” hoặc “N/A”

### 3. Error / Validation Message

| Tên           | Khi dùng                                             | Nội dung / Format    | Props / Thuộc tính                           | Ghi chú                                         |
| ------------- | ---------------------------------------------------- | -------------------- | -------------------------------------------- | ----------------------------------------------- |
| `ErrorText`   | Hiển thị lỗi dưới input                              | văn bản lỗi (string) | `message`, `visible`                         | màu đỏ chuẩn, font-size thống nhất              |
| `ErrorBanner` | Hiển thị lỗi mức cao (form submit lỗi, lỗi hệ thống) | tiêu đề + mô tả      | `title`, `message`, `type` (error / warning) | xuất hiện ở đầu form hoặc giữa trang            |
| `FieldError`  | Lỗi riêng cho từng trường                            | chuỗi nhỏ            | `fieldName`, `message`                       | liên kết với input thông qua `aria-describedby` |

#### Quy ước chung cho Error

* Màu lỗi: dùng `#d32f2f` (hoặc màu brand error)
* Font-size: nhỏ hơn font body một chút, ví dụ 12-14px
* Khoảng cách: cách trường input một khoảng cách thống nhất
* Ẩn / hiện: có animation (fade in / fade out) nếu cần

### 4. Popup / Tooltip

| Tên       | Mô tả                                          | Props / Thuộc tính                           | Biến thể                        | Ghi chú                                 |
| --------- | ---------------------------------------------- | -------------------------------------------- | ------------------------------- | --------------------------------------- |
| `Tooltip` | Hiển thị gợi chú nhỏ khi hover hoặc focus      | `content`, `placement`, `trigger`            | `hover`, `click`                | nếu nội dung dài nên chuyển sang Dialog |
| `Popup`   | Popup nhỏ, có thể tương tác (checkbox, button) | `content`, `placement`, `onClose`, `visible` | `hover`, `click`, `contextMenu` | cần xử lý click ngoài để đóng           |
| `Popover` | Popup có tiêu đề + nội dung                    | `title`, `content`, `placement`, `visible`   | tương tự Popup                  | dùng khi cần tiêu đề + body             |

#### Quy ước chung cho Popup / Tooltip

* Placement: top, bottom, left, right, topLeft, bottomRight, …
* Khoảng cách so với target element: cố định (ví dụ: 8px)
* Animation: fade + slide nhẹ
* Nếu chiều ngang màn hình nhỏ, nên tự động chuyển placement phù hợp
* Click outside / Esc để đóng

### 5. Dialog / Modal

| Tên             | Mô tả                        | Props / Thuộc tính                               | Biến thể / trạng thái                 | Ghi chú                              |
| --------------- | ---------------------------- | ------------------------------------------------ | ------------------------------------- | ------------------------------------ |
| `Modal`         | Hộp thoại modal lớn          | `title`, `visible`, `onOk`, `onCancel`, `footer` | `confirm`, `info`, `warning`, `error` | nếu nội dung dài có scroll bên trong |
| `ConfirmDialog` | Dialog để xác nhận hành động | `title`, `content`, `onConfirm`, `onCancel`      | —                                     | hai nút confirm + cancel             |
| `AlertDialog`   | Dialog thông báo đơn giản    | `title`, `message`, `onOk`                       | —                                     | chỉ nút OK hoặc nút đóng             |

#### Quy ước chung cho Dialog / Modal

* Z-index: cao hơn Popup / Tooltip / overlay khác
* Backdrop: mờ, có thể click để đóng hoặc không (tùy config)
* Kích thước chuẩn (small, medium, large)
* Nội dung scroll nếu vượt quá chiều cao màn hình
* Focus trap: khi mở dialog, focus phải giới hạn trong dialog
* ESC để đóng (khi allowed)

### 6. Paging / Pagination

| Tên            | Mô tả                             | Props / Thuộc tính                         | Biến thể                                 | Ghi chú                               |
| -------------- | --------------------------------- | ------------------------------------------ | ---------------------------------------- | ------------------------------------- |
| `Pagination`   | Phân trang cơ bản                 | `current`, `total`, `pageSize`, `onChange` | hiển thị số trang, prev/next, first/last | nếu nhiều trang, dùng ellipsis (`…`)  |
| `PagingSimple` | Phân trang đơn giản (prev / next) | `current`, `onPrev`, `onNext`              | —                                        | phù hợp list nhỏ                      |
| `Pager`        | Chỉ dòng số (1,2,3...)            | tương tự                                   | —                                        | không show tổng số, dùng khi ít trang |

#### Quy ước chung cho Paging

* Số trang hiển thị tối đa (ví dụ: 5 trang trước/sau)
* Kích thước nút số, prev/next: consistent design
* Disable trạng thái khi ở đầu/cuối
* Khoảng cách giữa các nút: thống nhất
* Accessibility: aria-label, keyboard navigation

---

### 7. Các Item bổ sung (Common)

* **Loader / Spinner**

  * `Spinner` / `LoadingIndicator`: hiển thị khi chờ dữ liệu
  * Props: `size`, `color`, `visible`
* **Badge / Tag**

  * `Badge` / `Tag`: hiển thị nhãn nhỏ
  * Props: `color`, `text`, `variant` (solid / outline)
* **Avatar**

  * `Avatar`: hiển thị ảnh người dùng hoặc placeholder
  * Props: `src`, `size`, `alt`, `fallback`
* **Breadcrumb / Steps**

  * `Breadcrumb`, `Steps`: hiển thị luồng / điều hướng
  * Props: `items`, `current`, `onChange`

## 🧩 Cấu trúc tài liệu / style guide đề xuất

```
/docs/
  common-components.md   ← tài liệu liệt kê components common
  button.md
  table.md
  dialog.md
  paging.md
  ...
```

Trong mỗi file (ví dụ `button.md`), bạn nên có:

1. **Mô tả** / lý do tồn tại component
2. **API / Props** chi tiết
3. **Trạng thái / biến thể** (các state: hover, active, disabled)
4. **Ví dụ sử dụng** (kèm snippet code)
5. **Quy ước / lưu ý** (kích thước, màu, khoảng cách, accessibility)
6. **Chú ý responsive / fallback / edge cases**
