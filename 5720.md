# User Story 3 – Xác định mục tiêu, MVP và kế hoạch sản phẩm

---

## 3. User Story & Feature

### 3.1 User Story cho Học viên (MVP)

- _As a student, I want to log in with the account provided by the academic officer, so that I can access the system securely._
- _As a student, I want to view my personal information and class details, so that I know my current enrollment status._
- _As a student, I want to check in using face recognition (TechEye), so that my attendance is recorded automatically._
- _As a student, I want to view my learning progress and grades, so that I can track my performance._

### 3.2 Feature dài hạn

- Quản lý lớp học (tạo, phân công, quản lý học viên).
- Quản lý tài khoản (giáo vụ).
- Báo cáo & thống kê tổng quan.
- Xuất dữ liệu Excel/PDF.
- Tích hợp API chính thức TechEye.
- Dashboard nâng cao.
