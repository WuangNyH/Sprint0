# 📄 Xác định các tính năng bắt buộc của item list: sort, search, paging...

## 1) Search — Tìm kiếm

**Mô tả:** 1 ô tìm kiếm chính cho quick search (tìm theo nhiều trường), có thể mở rộng thành Advanced Search.
**Behavior & yêu cầu**

* Quick search tìm across nhiều field (ví dụ: tên, email, mã).
* Debounce client-side (recommend 300ms).
* Configurable `minChars` (gợi ý ≥ 2).
* Hiển thị spinner khi loading.
* Show `Clear` để xóa search.
  **API params gợi ý:** `q=...`
  **Acceptance**
* [ ] Gõ text → sau debounce API được gọi.
* [ ] Kết quả khớp expected (partial/exact as spec).
* [ ] Clear reset list.

---

## 2) Sort — Sắp xếp

**Mô tả:** Sắp xếp theo cột (ít nhất single-column).
**Behavior & yêu cầu**

* Click header toggles `asc` ↔ `desc` (hoặc `none` → `asc` → `desc`).
* Hiển thị icon/indicator cho direction.
* Server-side sort (sort áp dụng trước paging).
* (Optional) Multi-column sort via Shift+Click or UI dialog.
  **API params gợi ý:** `sort=lastName:asc` hoặc `sort=lastName:asc,createdAt:desc`
  **Acceptance**
* [ ] Click header cho ra thứ tự đúng asc/desc.
* [ ] Kết quả trang 1..n tuân thủ sort server-side.

---

## 3) Paging — Phân trang

**Mô tả:** Phân trang page-based (or load-more/infinite).
**Behavior & yêu cầu**

* Hỗ trợ params `page` & `size`.
* Server trả `total` để hiển thị tổng item.
* Page size chọn được (10/20/50).
* Hiển thị range: `Hiển thị 1–20 trên 254`.
* Infinite scroll: có spinner & “Load more” fallback.
  **API params gợi ý:** `page=1&size=20`
  **Acceptance**
* [ ] Chuyển trang & page size thay đổi đúng và hiển thị range chính xác.
* [ ] Tổng số items từ server khớp UI.

---

## 4) Filters — Lọc (bắt buộc tối thiểu)

**Mô tả:** Lọc theo các trường chính (status, date range, role...).
**Behavior & yêu cầu**

* Support multi-filters (AND logic mặc định).
* Hiển thị active filter chips, có nút xóa từng filter & Clear all.
  **API params gợi ý:** `filters=status:active,role:student`
  **Acceptance**
* [ ] Áp filter → kết quả đúng.
* [ ] Chips phản ánh filter hiện hữu.

---

## 5) Column config (ít nhất show/hide)

**Mô tả:** Người dùng có thể ẩn/hiện cột; (persist optional).
**Acceptance**

* [ ] Ẩn/hiện cột ngay lập tức.
* [ ] Nếu lưu config: load config khi mở lại.

---

## 6) Row actions & Per-item operations

**Mô tả:** View, Edit, Delete (confirm), More.
**Acceptance**

* [ ] Click View/Edit mở đúng màn hình.
* [ ] Delete hiển thị confirm và thực thi đúng quyền.

---

## 7) Selection & Batch Actions

**Mô tả:** Checkbox per-row + Select all on page; batch actions toolbar.
**Behavior & yêu cầu**

* Option: “Select all results” (across pages) — show message rõ ràng.
* Batch API nhận list ids và trả success/fail list.
  **Acceptance**
* [ ] Chọn nhiều → toolbar hiển thị.
* [ ] Batch delete/export hoạt động và hiển thị kết quả từng id khi có lỗi.

---

## 8) Loading / Empty / Error states

**Mô tả:** Trạng thái hiển thị cần rõ ràng.
**Acceptance**

* [ ] Loading: spinner khi đang fetch.
* [ ] Empty: friendly message + CTA (Reset filters / Tạo mới).
* [ ] Error: toast hoặc alert với nút Retry.

---

## 9) Performance & Limits

**Yêu cầu**

* Server trả < 2s cho typical queries.
* Server-side paging & DB index cho fields search/sort.
* Enforce `maxPageSize` server-side.
  **Acceptance**
* [ ] Query mặc định trong SLA.
* [ ] Deep pages ko degrade performance nghiêm trọng.

---

## 10) Security & Authorization

**Yêu cầu**

* Kiểm tra quyền truy cập list và mọi action (view/edit/delete/export).
* 403 trả khi không có quyền.
  **Acceptance**
* [ ] Test: unauthorized user không thể truy xuất/act.

---

## 11) Accessibility (A11y)

**Yêu cầu**

* Keyboard navigable: header sort, pager, row selection, actions.
* ARIA roles: `table/list`, `aria-sort`, `aria-current` cho page.
* Contrast text/button meets WCAG AA.
  **Acceptance**
* [ ] Bảng điều khiển đầy đủ keyboard support.
* [ ] Screen reader đọc được trạng thái sort/paging.

---

## 12) API Contract mẫu (tối thiểu)

**Request**

```
GET /api/{resource}?page=1&size=20&q=nguyen&sort=lastName:asc&filters=status:active
```

**Response (mẫu)**

```json
{
  "data":[ /* items */ ],
  "meta": { "page":1, "size":20, "total":254, "pages":13 },
  "links": { "self":"...", "next":"...", "prev":"..." }
}
```

## 14) Gợi ý UX nhỏ

* Debounce 300ms cho search.
* Hiện summary nhỏ: `Sắp xếp: Họ (A→Z) • Lọc: active • Tìm: "nguyen"` để người dùng biết trạng thái hiện tại.
* Khi chọn “Select all results”, show: `Bạn đã chọn 254 items — Thực hiện hành động cho tất cả? [Áp dụng]`.
